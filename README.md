# touhou-lostword-flandre-scarlet 东方lostwrod大芙兰莱瓦汀
工程文件建议使用solidworks 2023及以上版本打开，这个模型开始是用工业光固化机来做的，部分地方偏差会有错误请注意。依旧700块投江传说，万恶之源这一块，下个月有空会抽出时间来重新完善。
# 附加
剑体内侧可加灯带来让他发光，可以用18650加5v变压板或者直接用5v电池充电，按钮型号为KAN-28。零件2和4推荐使用透明红亚克力，亚克力名字的推荐选用磨砂半透明渐变亚克力版，渐变色号是橙黄的（一般是ab2004），定制的时候可直接发cad图纸给商家，挂饰推荐自己打印，亚克力弄出来的容易断。做完可自己另外购买黑色塑料锁链来做装饰。
